# barrow.company

The holding page for Barrow Publishing Limited. Static HTML, no build step, no JavaScript, no third-party requests.

- `index.html` is the page. The wordmark is inline SVG.
- `assets/fonts/` holds Bricolage Grotesque (SIL Open Font License, see `OFL.txt`).
- `CNAME` binds the site to barrow.company on GitHub Pages.

Design record, proofs and the generator live in the private Barrow project workspace, not in this repository. Regenerate `index.html` from there rather than hand-editing the markup.
